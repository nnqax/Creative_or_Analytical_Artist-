# 🎨 Creative or Analytical Artist?! (Personality Quiz)

An interactive personality test built as a project for the **Girls Who Code (GWC) JavaScript course**.

### 🌟 About the Project
This quiz helps artists discover their primary creative approach:
- **Creative Artist:** Uses divergent thinking, spontaneous inspiration, and unconventional methods.
- **Analytical Artist:** Uses convergent thinking, technical execution, structure, and systematic rules.

### 💡 Features
- Interactive multiple-choice questions with visual options.
- Dynamic score calculation using JavaScript to deliver personalized results.
- Easy score reset functionality to retake the quiz.

### 🛠️ Built With
- **HTML5** — Semantic page structure and content markup
- **CSS3** — Custom styling, layouts, and responsive design
- **JavaScript (ES6)** — Interactive logic, event handling, and score calculation
